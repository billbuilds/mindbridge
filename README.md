# MindBridge

**Bridge the gap between AI output and human understanding.**

AI generates information at superhuman speed and density. Human brains are
biological — they can only absorb information through specific cognitive
patterns. MindBridge solves this mismatch.

## What It Does

A single markdown file (`SKILL.md`) that teaches AI agents how to communicate
the way human brains actually learn. Built on 4 research-backed frameworks:

- **Cognitive Load Theory** — Don't overload working memory (~4 chunks)
- **Feynman Technique** — If you can't explain it simply, you don't understand it
- **Multimedia Learning** — Words + visuals > words alone
- **Progressive Disclosure** — Essentials first, details on demand

## Usage

Copy `SKILL.md` into your AI agent's context (Copilot CLI, Claude Code,
Cursor, etc.), then use:

| Command | What it does |
|---------|-------------|
| `/learn` | AI teaches you using the best format |
| `/html` | Rich HTML preview in browser |
| `/md` | Markdown output |
| `/preview` | Preview recent conversation content |
